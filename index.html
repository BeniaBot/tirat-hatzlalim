בקשה להצטרף למשמרת

יש לך גרסה משלך? היא תופיע כאן אחרי אישור.

  1. לוחצים על העלאת גרסה למטה. צריך חשבון גיטהאב, וזה הכול.
  2. בשורת השם שמעל הקובץ כותבים את השם שלכם ואחריו לוכסן, למשל משה/, וגוררים פנימה את קובץ ה־HTML. אפשר להעלות כמה גרסאות לאותו שם.
  3. לוחצים Propose changes ואז Create pull request. אחרי אישור, הגרסה מופיעה בדף לבד.
