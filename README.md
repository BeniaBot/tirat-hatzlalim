# טירת הצללים · הגרסאות

משחק אימה שלם בקובץ HTML אחד, שעובד גם בלי אינטרנט. כל שומר לילה מביא את הגרסה שלו.

**לשחק ולהוריד:** https://beniabot.github.io/tirat-hatzlalim/

## איך מעלים גרסה

1. נכנסים ל[העלאת גרסה](https://github.com/BeniaBot/tirat-hatzlalim/upload/main/versions). צריך חשבון גיטהאב.
2. בשורת השם שמעל הקובץ כותבים את השם שלכם ואחריו לוכסן (למשל `משה/`), וגוררים פנימה את קובץ ה־HTML.
3. לוחצים **Propose changes** ואז **Create pull request**. אחרי אישור, הגרסה מופיעה בדף לבד.

קובץ HTML אחד לכל גרסה, עד 25 מגה. שם הקובץ הוא שם הגרסה שיופיע בדף. גרסה חדשה באותו שם מחליפה את הקודמת.
